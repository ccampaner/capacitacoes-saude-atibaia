# Portal de Capacitações Interativas • Saúde de Atibaia/SP

Repositório estático pronto para publicação via **GitHub Pages** contendo o menu inicial (`index.html`) e as 4 capacitações interativas com salvamento automático (`localStorage`) e emissão de certificado em PDF:

1. **`capacitacao_IA_saude.html`** — Inteligência Artificial Aplicada à Gestão e Rotina do SUS
2. **`capacitacao_lei_8080_sus.html`** — Lei Orgânica da Saúde (Lei Federal nº 8.080/1990)
3. **`capacitacao_LGPD_saude.html`** — Lei Geral de Proteção de Dados (LGPD) na Rotina da Saúde
4. **`curso_ia_desenvolvimento_softwares.html`** — Inteligência Artificial Aplicada ao Desenvolvimento de Softwares

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `capacitacoes-saude-atibaia`).
2. Envie os 5 arquivos HTML (`index.html` + os 4 arquivos de curso) para a raiz da branch `main`.
3. No repositório do GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment → Source**, selecione **Deploy from a branch**, escolha a branch **`main`** e a pasta **`/ (root)`**, e clique em **Save**.
5. Em 1 a 2 minutos, o portal estará no ar no endereço `https://seu-usuario.github.io/capacitacoes-saude-atibaia/`.
